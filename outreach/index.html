Welcome to GOLFIT

A multiplayer video game centered around the experience of minigolf. Developed by a team of four students at the University of Basel.

Get Started

About The Game

GolfIt is built on a client-server architecture where communication is handled through a custom-made network protocol. It provides a fun golf game with an interactive environment, aiming to bring friends together for competitive minigolf action.

Key Features

Multiplayer Action

Support for up to 6 players per lobby. Create or join lobbies and communicate via a real-time text chat.

Dynamic Physics

Friction-based deceleration, wall bounces, and interactive elements such as trees, walls, and bridges.

Competitive Logic

Game state tracking with stroke counts and finish-time tie-breakers. Automatic and unique golf ball color assignment.

Aim Indicator

Visual cone-shaped power and direction indicator for intuitive stroke control.

Custom Networking

A custom UDP-based protocol with reliable delivery for system and chat messages.

Modern Tech Stack

Powered by Java 25, JavaFX for the GUI, and Gradle as the build system.

Installation & Setup

Get started by downloading the source code from our repository. Building the project yourself ensures the correct graphical libraries are downloaded for your specific operating system (Windows, Mac, or Linux). Make sure you have Java 25 installed.

Download Game Source (.zip)

1. Download & Extract

# Download the zip file using the button above and extract it.
# Then, open your terminal and navigate into the extracted folder.
cd golfit-source

2. Compile the Game

# Use the Gradle wrapper to build the project and automatically download correct libraries
./gradlew build-cs108

3. Start the Server

# Run this command in your terminal to start the game server
java -jar build/libs/golfit-0.0.1-ALPHA.jar server <PORT>

4. Start the Client

# Open a new terminal window to connect as a player
java -jar build/libs/golfit-0.0.1-ALPHA.jar client <IP>:<PORT> <USER>
